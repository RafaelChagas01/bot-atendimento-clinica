Bot de atendimento para clínica

Uma clínica recebe as mesmas perguntas o dia todo: aceita meu convênio, quanto custa, que horas abre. Esse bot responde essas dúvidas no WhatsApp, anota pedidos de consulta e passa a conversa pra recepção quando precisa de uma pessoa.

A Odonto Prado é fictícia. Aqui o chat roda no navegador; o mesmo código atende pelo webhook oficial do WhatsApp.
